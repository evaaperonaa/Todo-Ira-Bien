# Todo Irá Bien 💙

Desarrollo de una página web profesional para una psicóloga y psicoterapeuta, diseñada para presentar sus servicios, explicar su metodología de trabajo y facilitar el contacto con posibles pacientes.

## ✨ Sobre el proyecto

El objetivo es crear una presencia digital profesional, accesible y cercana que permita conocer los servicios y especialidades de la profesional.

La web incluirá información sobre las distintas áreas de atención, la metodología de trabajo y las opciones de contacto, con un diseño adaptable a ordenadores, tabletas y móviles.

## 🛠️ Tecnologías utilizadas

- Angular
- TypeScript
- HTML5
- CSS3
- Git y GitHub

- Crear una web profesional, moderna y fácil de utilizar.
